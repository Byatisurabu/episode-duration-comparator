# 📄 HLE — High Level Engineering Document

## Проект: Сервис сравнения длительности эпизодов

**Версия:** 0.2  
**Статус:** MVP — core функционал завершён, идёт подготовка к альфа-релизу для узкого круга  
**Формат:** итерационная разработка  
**Тип проекта:** анонимный pet-project

Дата актуализации: 25 февраля 2026

---

### 1. Общее описание проекта

**Цель**  
Создание инструмента для сравнения длительности серий/сезонов одного и того же сериала на разных платформах с целью выявления возможных купюр, цензуры или разных монтажных версий.

**Текущий охват**  
- Сравнение IMDb ↔ Amediateka  
- Ручной ввод двух ссылок → таблица с разницей в минутах и процентах  
- Цветовая индикация (с учётом порога ≤1 мин = незначительная разница)

### Ближайшие шаги (февраль–март 2026)

1. **Этап 1.9 — Контейнеризация**  
   Цель: запуск одной командой `docker compose up`  
   - Dockerfile (python:3.11-slim или 3.12-slim)  
   - docker-compose.yml (сервис + порт 8000)  
   - .dockerignore  
   - Проверка: локальный запуск + доступ через браузер

2. **Этап 1.10 — Выбор сезона из списка**  
   Цель: запуск одной командой `docker compose up`  
   - Dockerfile (python:3.11-slim или 3.12-slim)  
   - docker-compose.yml (сервис + порт 8000)  
   - .dockerignore  
   - Проверка: локальный запуск + доступ через браузер   

3. **Этап 2.1 — Telegram-бот (альфа-релиз для своих)**  
   Цель: удобный доступ для тебя и семьи без браузера  
   - python-telegram-bot + webhook / polling  
   - Команда /start + обработка двух ссылок в сообщении  
   - Ответ в виде markdown-таблицы или текста с эмодзи  
   - Локальный запуск + ngrok для теста  
   - Опционально: запуск на домашнем ПК с внешним доступом (через reverse proxy / Cloudflare Tunnel / VPS)

4. **Этап 2.2 — Решение по постоянному запуску**  
   Варианты:  
   - Домашний ПК + Cloudflare Tunnel / ngrok paid / reverse proxy  
   - Минимальный VPS (Hetzner ~3–5 €/мес) с белым IP  
   - **Не делать** публичный деплой на PaaS (Render/Railway/Fly) из-за банов

5. **Этап 2.3 — База + кэширование (если бот станет популярным среди своих)**  
   - SQLite / TinyDB для истории сравнений  
   - Кэширование результатов (redis или файлы)  
   - Команда /history в боте

### Риски и ограничения (актуальные на февраль 2026)

- Скрейпинг IMDb и Amediateka → высокий риск блокировок по IP  
- Публичный веб-сайт → почти гарантированно умрёт за 1–4 недели  
- Telegram-бот → самый живучий вариант для личного / семейного использования  
- Долгосрочная поддержка → нужна ротация прокси / user-agent / переход на API (если появятся)
