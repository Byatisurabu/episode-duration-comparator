# 1. Общее описание проекта

## 1.1 Цель

Создание веб-сервиса, позволяющего сравнивать длительность серий/фильмов на различных онлайн-платформах с целью выявления возможных сокращений контента.

Сервис:

* принимает два URL
* извлекает длительность серий
* сравнивает тайминги
* выводит процентное различие
* в дальнейшем сохраняет результаты

# 5. Архитектурные принципы

## 5.1 Pattern: Strategy для скрейпинга

```python
BaseScraper
 ├── ImdbScraper
 ├── AmediatekaScraper
 ├── OkkoScraper
 └── KinopoiskScraper
```

Каждый скрейпер возвращает унифицированную структуру:

```python
Episode(
    season: int,
    episode: int,
    title: str,
    duration_min: int
)
```

---

## 5.2 Нормализация

Обязательная конвертация:

* 1h 4m → 64
* 01:02:00 → 62
* 52 min → 52

---

## 5.3 Comparison Engine

Формула:

```
difference = compared - baseline
percent = (difference / baseline) * 100
```

Если:

* |percent| < 3 → возможно различия версий
* ≥ 5 → потенциальное сокращение
